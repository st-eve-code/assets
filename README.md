# Assets

Media files used by the Katika apps, including images and background music such as the audio for the Tic-Tac-Toe home screen.

## Layout

- `app/` holds the files for the app assets.
- `assets/` holds the shared media files.

Add new files in the matching folder, and keep file names lowercase with hyphens, for example `ttt-home-music.mp3`.
